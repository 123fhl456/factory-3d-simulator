这是什么

    
本站是「工厂具身智能体 6G 方案」配套的车间 3D 实时仿真模拟器：按方案文档场景要求建模（AGV、无人叉车、协作机械臂、纸箱、金属堆垛架、集装箱，全部标注材质反射系数 ρ），可实时调参观察 KPI 变化，并演示 RIS 智能表面多板协同波束赋形的补盲过程。

    
核心功能

    
    
      
  • 3D 场景：Three.js 渲染，拖拽旋转 / 缩放，AGV 与叉车实时运动，波束线可视化
    • 
      
  • 右侧控制面板：AGV 数量、速度、叉车数、金属遮挡深度、RIS 面板数、基站节点、遮挡预测窗口、通感一体、算力切分策略、RIS 阵列开关矩阵
    • 
      
  • 底部 KPI：中断率 / 时延 P95 / 遥感占空比 / 吞吐率 / 任务成功率 / 定位误差，均带基线对比（基线：中断 3.41 次/h、吞吐 38Mbps → 优化后 0.03 次/h、211Mbps）
    • 
      
  • 顶部五步管线：建图 → 传播计算 → 遮挡预测 → 相位决策 → 执行补盲
    •
