# 工厂具身智能体 · 6G 算网协同车间仿真模拟器（源代码）

与方案文档逐项对齐的车间 3D 实时仿真模拟器。**所有场景参数与指标值均取自方案文档原文，未作外推或美化**；点模拟器右上角「数据来源」可查看每个数值的出处。

## 目录结构

```
├── sim.html                单文件完整版（three.js 已内联，双击即用，可直接部署）
└── source/
    ├── index.html          模拟器页面骨架 + 全部样式
    └── js/
        ├── app.js          ★ 核心业务逻辑（想改功能改这个）
        ├── three.min.js    Three.js 渲染引擎（第三方库，未改动）
        └── OrbitControls.js 3D 视角控制（第三方库，未改动）
```

## 如何运行

方式一：双击 `sim.html` 直接用浏览器打开（Chrome / Edge / Safari 均可）。

方式二（推荐）：在本目录起一个本地服务：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 场景参数（文档：仿真平台 / 部署清单）

- 厂房 **60 m × 40 m × 8 m**；**12 组**金属货架；**4 台**协作机器人；**2 处**堆垛区（纸箱 / 集装箱）
- **20 台** AGV @ **1.2 m/s**；无人叉车；无人机送急件
- **4 个**分布式接入点（pRRU，毫米波 / Sub-6 双频）
- 智能超表面 **12—16 块**，每块 **0.6 m × 0.6 m、256 单元、1-bit 相位**，贴装于立柱 / 货架侧板 / 天花板，无源免布线
- 控制指令周期 5 ms；视觉上行 4 路 1080p@30；仿真折算 72 小时

## 底部八项指标（文档：八项指标表 + 仿真对照表）

| 指标 | 基线 | 方案 | 目标 |
|---|---|---|---|
| 端到端动作闭环时延 P99 | 96 ms | 18.6 ms | ≤ 20 ms |
| 遮挡区链路中断频次 | 3.4 次/h | 0.06 次/h | ≤ 0.1 次/h |
| 单站盲区面积占比 | 8%（8%—15%） | 1.9% | ≤ 2% |
| 非视距定位误差 | 42 cm | 7.8 cm | ≤ 10 cm |
| 单机可用等效算力 | 20—40 TOPS | 500 TOPS | ≥ 500 TOPS |
| 单机算力与通信 BOM | 100%（1.8 万） | 60%（验收标尺；1.8→1.1 万约 −39%） | ≤ 60% |
| 换任务重配置时间 | 4 h | 10 min | ≤ 10 min |
| 单机上行吞吐 | 60 Mbps | 300 Mbps | ≥ 300 Mbps |

其他仿真结果（文档原值）：遮挡区接收功率 −96.2 → −83.8 dBm（+12.4 dB）；遮挡区吞吐 38 → 210 Mbps（5.5 倍）；波束预测命中率 91.3% / 98.7%（Top1 / Top3）；切换中断 120 → 8 ms；相位决策时延 4.2 ms；任务成功率 纯云 82% / 纯端 76% → 方案 96.3%。

## 五步管线

建图（3DGS 语义地图 · 材质 ρ 标注）→ 传播计算（射线追踪 · 50 ms 周期 · 孪生误差 ≤2 dB）→ 遮挡预测（提前 300—500 ms）→ 相位决策（慢环 1 Hz 面板组合 / 快环 20 Hz 相位码字）→ 执行补盲（1-bit PIN · +12.4 dB）

## 技术栈

纯前端零依赖（除 Three.js），无需安装任何包。3D 场景为实时动态演示，指标数值按文档口径标定，不替代射线追踪仿真结果。
