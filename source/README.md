# 工厂具身智能体 · 车间实时仿真 3D 模拟器（源代码）

与线上发布版（工厂沙盘）、PPT 引用版完全一致的 3D 模拟器源代码。

## 目录结构

```
3D工厂模拟器源代码/
├── index.html             页面骨架 + 全部样式（CSS）
└── js/
    ├── app.js             ★ 核心业务逻辑（约 1100 行，想改功能改这个）
    ├── three.min.js       Three.js r134 渲染引擎（第三方库，未改动）
    └── OrbitControls.js   3D 视角控制（拖拽旋转 / 滚轮缩放）
```

## 如何运行

方式一：直接双击 `index.html` 用浏览器打开（Chrome / Edge 均可）。

方式二（推荐，更稳定）：在本目录下起一个本地服务：

```bash
cd 3D工厂模拟器源代码
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 功能说明（与方案文档对齐）

- **场景**：5G-A 智联车间，含货架、机械臂（p=0.73 协作机械臂）、叉车（p=0.82）、
  金属堆垛架（p=0.80）、纸箱（p=0.08）、集装箱（p=0.90），
  每类物体标注了材质反射系数 ρ。
- **右侧控制面板**：AGV 数量、行驶速度、无人叉车、金属遮挡深度、
  RIS 智能反射面数量、5G 基站节点、遮挡预测窗口、通感一体开关、
  封装&实时可视化开关、算力切分策略、RIS 阵列开关矩阵。
- **底部 KPI**：信号中断率、端到端时延 P95、遥感占空比、吞吐率、任务成功率、
  单据定位误差 —— 每项均显示"基线对比"（基线：中断 3.41 次/h、吞吐 38Mbps）。
- **顶部五步管线**：建图 → 传播计算 → 遮挡预测 → 相位决策 → 执行补盲，
  演示数字孪生"慢环 1Hz + 快环 20Hz"双环工作流。
- 拖滑块 / 点开关实时生效；点"演示模式"自动推演；左上可切换
  "基线（无优化）/ 6G 联合优化"对比。

## 技术栈

纯前端零依赖（除 Three.js），无需安装任何包。
WebGL 渲染，物理参数（材质反射、路径损耗、遮挡预测）为文档口径的简化仿真模型。
